AWS Services

The following AWS services are used to operate this platform. AWS SDKs are licensed under the Apache License 2.0. The services themselves are proprietary to Amazon Web Services, Inc.

  • AWS Lambda — serverless compute for license, bond, WC verification, card scan, and presigned URL generation
  • Amazon API Gateway — REST API routing all Lambda endpoints
  • Amazon DynamoDB — primary data store for the contractor directory (275,390+ CA records)
  • Amazon S3 — temporary storage for business card scan uploads (24h auto-delete)
  • AWS Textract — OCR and form extraction for the business card scanner
  • AWS Systems Manager Parameter Store — secure storage for Bright Data credentials
  • Amazon ECR — container image registry for Lambda Docker deployments
